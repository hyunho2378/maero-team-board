# 마에로 팀 보드

팀 버터와플이 같이 쓰는 화면 4개입니다. 마에로 HQ와 같은 디자인에 강조색만 파랑으로 바꿨습니다.

## 화면

| 화면 | 하는 일 |
| --- | --- |
| 캘린더 (첫 화면) | 달력에서 날짜를 누르면 그날 일정이 보여요. 맨 위에 가장 가까운 마감 한 줄 |
| 해야 할 일 | 동그라미를 누르면 끝난 일로 옮겨져요. 담당 버튼으로 사람별 보기 |
| 돈 쓴 것 | 맨 위에 쓴 돈과 남은 돈 (활동자금 200만 원 기준, 결제 완료만 더함) |
| 미팅 기록 | 목록에서 누르면 정한 것과 다음 할 일을 크게 볼 수 있어요 |

## 쓰는 법

1. 오른쪽 위 파란 버튼(일정, 할 일, 지출, 새 미팅)으로 새로 적어요
2. 줄을 누르면 고치는 창이 열려요. 저장을 누르면 끝
3. 지우기는 고치는 창 맨 아래 빨간 글씨 버튼이에요. 바로 지워지니 한 번 더 확인하고 눌러요
4. 영수증은 드라이브에 사진을 올리고 링크를 붙여 넣어요
5. 아이폰은 사파리 공유 버튼에서 홈 화면에 추가하면 앱처럼 열려요

## 저장 위치

- 팀 시트 연결 주소(VITE_ENDPOINT)가 들어간 배포본은 구글 시트 한 곳에 저장돼요. 다른 팀원 화면에는 다시 열거나 1분 안에 반영돼요
- 연결 주소가 없으면 이 브라우저에만 저장돼요. 왼쪽 메뉴 아래(넓은 화면)에 어느 쪽인지 적혀 있어요

## 만드는 사람용

- 개발: `npm install` 후 `npm run dev`
- 빌드: `VITE_BASE="/저장소이름/" npm run build`
- 시트 연결: "apps-script/Code.gs" 맨 위 설명대로 웹앱을 배포하고, 저장소 비밀값 VITE_ENDPOINT, VITE_TEAM_KEY 두 개를 넣어요. 키 값은 파일에 적지 않아요
- 배포: main에 올리면 ".github/workflows/pages.yml"이 GitHub Pages로 올려요
